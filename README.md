## 🔭 What I'm building now

A major current side project is **ComplianceSuite** — an evidence-driven compliance platform aimed initially at agricultural, ethical and social compliance.

Most compliance software treats compliance like a checklist:

> Upload document. Tick box. Repeat.

Real compliance doesn't work that way.

The same evidence, risks, people and corrective actions frequently span multiple standards, audits and operational processes.

ComplianceSuite explores a different architecture:

* One evidence source linked across multiple requirements
* Approval and expiry management
* Notifications and escalation
* Immutable evidence and audit history
* Consultant, client and auditor workflows
* Multiple compliance standards in one platform
* Offline-capable field workflows
* Searchable regulatory and standards knowledge
* AI-assisted compliance and knowledge tooling

The technology stack currently centres around **.NET, Angular, PostgreSQL, secure APIs and modern CI/CD**.

## 🤖 AI-assisted engineering

I'm very interested in what happens when AI becomes part of the **entire software-development lifecycle**, rather than merely an autocomplete tool.

I'm experimenting extensively with AI-assisted workflows for:

* Architecture and system design
* Implementation
* Code review
* Documentation
* Maintaining project context
* Translating business-domain knowledge into software
* Regression and security analysis
* Keeping implementation and architectural decisions aligned

The interesting problem isn't simply:

**"Can AI write the code?"**

It is:

**"Can we preserve enough context that the system we're building tomorrow still reflects the decisions we made today?"**
